# Εφαρμογή πειραματισμού με την "Εικασία του Goldbach"
*Κάθε άρτιος ακέραιος μεγαλύτερος του 2 μπορεί να γραφτεί ως άθροισμα δύο πρώτων αριθμών(;)*

**Χρήση VS-code**

- Το πρόγραμμα πρέπει να διαβάζει επαναλαμβανόμενα από την πρότυπη είσοδο (stdin) έναν ακέραιο και έναν χαρακτήρα επιλογής

- Το πρόγραμμά σας θα πρέπει να μπορεί να διαχειριστεί αριθμούς στο εύρος : 0 ≤ n ≤ 10.000.000.000

- Μετά την ανάγνωση του αριθμού, το πρόγραμμα πρέπει να διαβάζει έναν χαρακτήρα:
  - p για έλεγχο πρώτου αριθμού,
  - g για έλεγχο Goldbach

- Προκειμένου η απάντηση να είναι μοναδική (και γρήγορη), για τον έλεγχο Goldbach το πρόγραμμά σας πρέπει να τυπώνει το ζεύγος n = p + q με p ≤ q όπου ο p είναι ο μικρότερος δυνατός πρώτος
  Ο μικρότερος από τους δύο πρώτους (p) τυπώνεται πρώτος.
  Για παράδειγμα, για το 10 η μόνη αποδεκτή απάντηση είναι 10 = 3 + 7

- Το αρχείο C που θα υποβληθεί πρέπει να μεταγλωττίζεται χωρίς ειδοποιήσεις για λάθη
  `gcc -O0 -m32 -Wall -Wextra -Werror -pedantic -o goldbach goldbach.c`

ex.
$ gcc -O0 -m32 -Wall -Wextra -Werror -pedantic -o goldbach goldbach.c
$ ./goldbach
Give me a number: 17
Choose how to test 17 - ('p' for prime, 'g' for goldbach) p
17 is prime
Give me a number: 42
Choose how to test 42 - ('p' for prime, 'g' for goldbach) p
42 is not prime
